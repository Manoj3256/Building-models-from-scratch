# Building Models From Scratch

Machine learning algorithms implemented from scratch for the core logic. Each project includes the math derivation, and algorithm.

## Models

| Model | Type |
|---|---|
| Linear Regression | Regression |
| Logistic Regression | Classification |
| Decision Tree Classifier | Classification |
| Random Forest Classification | Ensemble |
| K-Means Clustering | Unsupervised |

## Why

Built to understand what's happening under the hood of standard ML libraries — rather than just calling `.fit()`

## Structure

Each folder contains:
- Implementation (NumPy)
- README with math + algorithm steps
- Notebook 

## Stack

Python, NumPy, Jupyter
