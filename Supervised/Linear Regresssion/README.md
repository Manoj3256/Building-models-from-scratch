# This is Linear Regression From Scratch

## Project Overview
This project(model.py) implements Linear Regression from scratch using NumPy without using Scikit-Learn's LinearRegression model.

## Objectives
- Understand Linear Regression mathematics
- Implement Gradient Descent
- Train a model from scratch
- Visualize training progress

## Mathematical Formula

Prediction:

y = m*x + b

Cost Function:

J(m,b) = (1/n)*sum(y_pred - y)^2

Gradient Descent:

m = m - α * dm
b = b - α * db

## Project Workflow

1. Load dataset
2. Visualize data
3. Implement Linear Regression
4. Train using Gradient Descent
5. Evaluate model
6. Visualize predictions
